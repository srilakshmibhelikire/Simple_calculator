 🧮 Simple Continuous CLI Calculator

A beginner-friendly Python project that performs basic arithmetic operations using a command-line interface (CLI).


 🚀 Features

➕ Addition  
➖ Subtraction  
✖️ Multiplication  
➗ Division  
🔁 Continuous usage (no restart needed)  
🛑 Exit option  
⚠️ Handles division by zero  


 🛠️ Technologies Used

- Python 🐍  
- if-else conditions  
- while loop  
- input() function  


 ▶️ How to Run

```bash
python calculator.py
