🧮 Simple Continuous CLI Calculator

A beginner-friendly Python project that performs basic arithmetic operations using a command-line interface (CLI).  
This project is designed to practice **Python basics, user input, loops, and conditional statements**.



 🚀 Features

✔ Addition ➕  
✔ Subtraction ➖  
✔ Multiplication ✖️  
✔ Division ➗  
✔ Continuous usage (no need to restart program) 🔁  
✔ Exit option 🛑  
✔ Handles division by zero ⚠️  
✔ Input validation for safe usage ✅  



 🛠️ Technologies Used

- Python 🐍  
- Conditional Statements (`if-elif-else`)  
- Loops (`while True`)  
- User Input (`input()`)
